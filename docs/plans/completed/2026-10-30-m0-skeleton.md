# M0 — Skeleton

## Purpose

Stand up the Cargo workspace, pin ty, isolate the adapter crate, and report
direct `time.sleep` inside `async def` with maturin packaging so `uvx` works.

## Progress

- [x] 2026-10-30: Workspace crates `async_doctor_core`, `async_doctor_rules`, `async_doctor_ty`, `async_doctor` (binary `async-doctor`).
- [x] 2026-10-30: All ty/ruff usage isolated in `async_doctor_ty`, pinned to **0.0.20**.
- [x] 2026-10-30: Custom salsa `AsyncDoctorDb` implementing `ty_python_semantic::Db`.
- [x] 2026-10-30: Direct `time.sleep` in `async def`, JSON/text, exit codes, maturin.
- [x] 2026-10-30: No config file.

## Surprises & Discoveries

- ty/ruff crates are internal components with no semver promise — exact `=` pins required.
- typeshed via `ty_vendored` needs an Apache-2.0 notice in the repo.
