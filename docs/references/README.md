# References

Third-party material pinned in the repo so agents read the version we use
instead of guessing from training data: `llms.txt` files, API excerpts, spec
sections.

- One file per source, named after it (`<library>-llms.txt`, `<spec>-<section>.md`).
- First lines of each file: source URL, version, and the date fetched.
- Keep only what this project uses; trim the rest.
- Refresh when the dependency version changes.

No pinned third-party reference files yet. Add one when an agent would otherwise
guess an API from training data.
